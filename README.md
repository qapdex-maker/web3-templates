# 🌐 Web3 Templates

Willkommen bei den **Web3 Templates**! Diese Repository enthält eine Sammlung von interaktiven, hochmodernen Web-Templates für Forschungs- und Testzwecke.

Alle HTML-Dateien sind direkt über **GitHub Pages** aufrufbar und können interaktiv im Browser getestet werden.

## 🛠️ Benutzung & Entwicklung

1. **Vorschau:** Klicke einfach auf die Links in der Spalte **Live-Demo**, um das jeweilige Template direkt in Deinem Browser anzuzeigen.
2. **Quellcode:** Über den Link **Quellcode** gelangst Du direkt zur entsprechenden Datei in diesem Repository, um den Code zu analysieren oder anzupassen.
